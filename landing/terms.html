3. Local Desktop Execution & System Rights

EvryFloat executes natively on Windows 10 and Windows 11 as a desktop process. To provide its core features, the software requires the following local OS capabilities:

  • Registering global Windows keyboard shortcuts (Alt + Space).
  • Accessing and monitoring local system clipboard changes to maintain clipboard history.
  • Writing local databases and cache files to %APPDATA%\EVRY.
  • Querying local hardware metrics (CPU, RAM, Battery) via Windows APIs.
