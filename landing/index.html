Overview

01 / Concept

What is EvryFloat?

A native floating HUD inspired by the dynamic island. Glides flush to the top of your screen, opening instantly when summoned and staying out of your sight when working.

Tauri 2.0 • Rust Core
02 / Audience

Who is it for?

Presenters delivering talks, developers needing fast clipboard & staging, remote professionals on calls, and anyone who wants instant access without window clutter.

Engineers & Speakers
03 / Environment

Where to use it?

Floats globally above all Windows applications, full-screen browsers, games, or IDEs. Automatically shielded from screenshares during Zoom, Teams, and Google Meet.

Global Windows Overlay
04 / Workflow

How to use it?

Press Alt + Space to toggle. Select your tool with arrow keys or click. Press Escape or click outside to collapse back to the notch.

Architecture

Zero Electron. Zero Cloud Telemetry.

EvryFloat is written natively in Rust using Tauri 2.0. It requires zero accounts, makes zero remote telemetry calls, and keeps all your data strictly on your local machine in SQLite.

✓ Memory Footprint: ~28MB idle RAM consumption.
✓ Local Storage: Stored under %APPDATA%\EVRY
✓ Air-Gapped: 100% functional without an active internet connection.
TECHNICAL SPECIFICATIONS WIN_X64

Core Engine: Rust 1.84 + Tauri v2.5.1

Frontend: React 19 + TypeScript + Tailwind

Database: SQLite (rusqlite with WAL mode)

Image Hashing: BLAKE3 (64-bit digest deduplication)

Screen Shield: SetWindowDisplayAffinity (WDA_EXCLUDEFROMCAPTURE)

Global Trigger: Windows GlobalHook (ALT + SPACE)
