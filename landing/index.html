Core Identity

Built for High-Velocity Modern Work

Windows 11 is powerful, but constant window switching destroys your focus. EvryFloat brings context to your fingertips without ever taking you out of flow.

What is it?

A native Windows 11 Dynamic Island & floating productivity notch. It rests quietly as a 44px pill flush against your top bezel and expands smoothly into a 350px powerhouse HUD whenever summoned.

• 100% Offline SQLite
• Under 30MB RAM

Who can use this?

Presenters: Read talking points directly under the webcam.
Developers: Instant clipboard history, hex inspection & file shelf.
Students & Pros: Focus Pomodoro sessions, master volume & scratchpad notes.

• Universal appeal
• Zero learning curve

Where to use it?

Live Meetings: Teams, Zoom, Meet, OBS (hidden via WDA_EXCLUDEFROMCAPTURE).
Dual Monitors: Anchored comfortably to top center.
Any App: Floats above full-screen browsers, IDEs, games, or spreadsheets.

• Always on top
• Screen-share invisible

How to use it?

1. Summon: Hit Alt+Space or click the notch pill.
2. Switch: Click any of the 8 quick tiles or press hotkeys.
3. Return: Press Esc or click away to collapse seamlessly.

• Fast keyboard flow
• Instant mouse glance

All Built-in Modules

9 Powerful Tools. Zero Clutter.

Every module is strictly tuned to a unified 350px expanded height, ensuring a smooth, harmonious desktop experience.

Webcam Aligned

1. Distraction-Free Prompter

Positioned directly beneath your webcam lens so your eyes look right at your audience while delivering talks or interviews.

  • Zero Distraction: Toolbar fades to 0% opacity during auto-scroll.
  • Smooth Scrolling: 60 FPS sub-pixel speeds (0.5x, 1x, 1.5x, 2x) & Spacebar toggle.
  • Notes Sync: Import or save notes directly to local SQLite.
  • Eye-Level Guide: Subtle dashed horizon marker aligned under webcam.
Key: Teleprompter.tsx • Local Storage Auto-Save
Native Drag & Drop

2. Clipboard History

High-performance clipboard memory without cloud telemetry. Zero heavy base64 strings in SQLite.

  • Native Bitmaps: Screenshots saved to disk with BLAKE3 deduplication.
  • Drag OUT & Drop IN: Drag clips directly to Slack, VS Code, or drop files in.
  • Type Filter Pills: All, Images, Text, Colors (Hex), and Links.
  • Copy vs Paste: Click to copy, double-click or Enter to paste & collapse.
Key: ClipboardManager.tsx • %APPDATA%\EVRY
3-Row Layout

3. Quick Controls & System

Compact hardware metrics and quick system toggles inspired by macOS Control Center and modern HUDs.

  • CPU & RAM Gauges: Real-time utilization bars and used/total memory.
  • 1-Click Shortcuts: Wi-Fi, Bluetooth, Display Brightness, Windows Settings.
  • Master Volume: Instant Mute, Volume Down, and Volume Up buttons.
  • Header Power Status: Live battery % and charging state badge.
Key: QuickActions.tsx • Compact 290px Grid
Alt + Space

4. Universal Command Search

Raycast-style unified search bar for applications, files, calculations, and custom prefixes.

  • Instant App Launching: Scans Start Menu and Program Files.
  • Math & Dictionary: Real-time math evaluation and definition lookups.
  • Specialized Prefixes: Prefix `kill` to end tasks, `clip` to find clips.
  • Text Snippets: Quick insertion for common symbols and phrases.
Key: CommandSearch.tsx • Windows Shell Exec
SQLite Local

5. Notes & Reminders

Instant scratchpad for thoughts, meeting notes, code snippets, and time-stamped checklist reminders.

  • Local Notes: Persistent title + body storage saved automatically.
  • Due Date Reminders: Set checklist tasks with date/time trackers.
  • Seamless Sync: Seamlessly shared with the Teleprompter module.
  • Zero Latency: Powered directly by embedded SQLite engine.
Key: NotesReminders.tsx • SQLite Database
Audio Chime

6. Focus & Pomodoro

Integrated focus management with live countdown rendering directly inside the top notch pill.

  • Custom Intervals: Work duration, short breaks, and long break intervals.
  • Pill Activity: Live timer countdown visible in top notch pill.
  • Sound Notification: Native audio alert upon session completion.
  • Session Analytics: Tracks daily streak and sessions completed.
Key: PomodoroTimer.tsx • Background Rust Worker
SMTC Native

7. Now Playing & Media

Live Spotify, YouTube, Apple Music, and browser audio player integration through Windows Media Transport.

  • Track Metadata: Live song title, artist, and playback status.
  • Transport Controls: Play, pause, skip previous, and skip next.
  • Dynamic Island Pill: Shows currently playing song in the top notch.
  • Volume Step: Fine-grained master volume adjustments.
Key: MediaControls.tsx • Windows SMTC API
Universal Stash

8. Holding Drop Shelf

A temporary clipboard shelf for holding files, folders, URLs, and code snippets while switching between apps.

  • Multi-Item Staging: Drag 10 files into the notch, drop them later in email.
  • Batch Actions: Select all, copy file paths, or reveal in Explorer.
  • Risk Detection: Inspects file extensions and internet origin flags.
  • LAN Sharing: Generate local Wi-Fi QR code for peer downloads.
Key: DropShelf.tsx • Local Staging Cache
Kernel Affinity

9. Privacy Shield & Settings

Hardware-level screen capture protection and deep system settings located inside the Preferences view.

  • Capture Exclusion: Powered by `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`.
  • Invisible on Shares: Hides EVRY completely from Zoom, Teams, & OBS.
  • Opacity Slider: Fine-tune transparency from 40% to 100%.
  • Retention Policies: Auto-prune unpinned clipboard items after 7-90 days.
Key: SettingsView.tsx • Windows Display Affinity API

Under the Hood

Engineered for Performance.
100% Offline & Private.

Unlike modern desktop apps built on bloated Electron frameworks that consume gigabytes of memory, EvryFloat is built on Tauri 2.0 and Rust.

0% Cloud Analytics or Telemetry

Your clips, presentation scripts, and notes never touch any remote server. Everything is stored locally on your machine.

Native Windows 11 API Integration

Direct integration with Windows GlobalHook, SMTC Media, Display Affinity, and PowerShell registry commands.

Instant Summoning & Zero Latency

Window heights adjust smoothly (44px collapsed to 350px expanded) with native hardware acceleration.
