Privacy Policy

Effective Date: November 21, 2026 • Version 1.0

The Zero-Telemetry Commitment

EvryFloat is strictly an offline desktop application. It contains zero tracking codes, zero cloud telemetry, and zero remote analytics. Everything you copy, write, calculate, or stage stays entirely on your local machine.

1. Data Collected & Stored Locally

EvryFloat functions by saving specific productivity data to your local hard drive under your Windows user profile (%APPDATA%\EVRY):

  • Clipboard History: Text clips, URLs, hex colors, and code snippets captured from your Windows clipboard into a local SQLite database (evry.db).
  • Screenshots & Bitmap Images: Copied images are stored as local files under %APPDATA%\EVRY\clip_images with BLAKE3 cryptographic hashes to prevent duplicates.
  • Notes & Prompter Scripts: User-written notes, checklist reminders, and teleprompter texts are stored in your local SQLite database.
  • User Preferences: Overlay opacity, hotkey registrations, and retention policies stored in standard local storage.

2. Network Activity & External Communications

EvryFloat is completely air-gapped:

  • The application initiates no outbound HTTP/HTTPS requests to external servers.
  • No accounts, sign-ins, passwords, or personal credentials are required or stored.
  • Local Area Network (LAN) sharing via Drop Shelf is entirely peer-to-peer over your private local Wi-Fi and never routes through third-party relays.

3. Hardware Screen Capture Protection (Privacy Shield)

EvryFloat includes native integration with the Windows SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE) API.

When enabled in Settings, the Windows Desktop Window Manager (DWM) excludes the EvryFloat window from any screen recording or sharing software (including Zoom, Microsoft Teams, Google Meet, OBS Studio, Discord, and Windows Snipping Tool). This ensures private notes and teleprompter scripts cannot be viewed by meeting participants.

4. Data Retention & Deletion

You have complete, absolute control over all data saved by EvryFloat:

  • One-Click Clear: You can purge clipboard items or delete notes anytime within the application.
  • Auto-Purge Policy: Set automatic expiration for unpinned items (7, 30, or 90 days) in Settings.
  • Complete Uninstall: Deleting the %APPDATA%\EVRY folder permanently removes 100% of the database, images, and user history from your PC.

5. Updates & Questions

As an open-source project, our codebase is fully auditable on GitHub. If you have questions about privacy, open an inquiry on our Contact page.
